## Estructura de archivos

### Paquete de lanzamiento

```bash
│  liquid-dark.css
│  liquid-ink-dark.css
│  liquid-ink.css
│  liquid.css
│  Demo.md
│  Document.md
│
└─liquid # archivos de fuentes usados por el tema
```

### Código fuente

```bash
├─.github
│  └─workflows
├─dist # archivos CSS combinados
├─font # todos los archivos de fuentes
├─media # imágenes de vista previa del tema Liquid
└─src # código fuente
   ├─Deploy # scripts de Python para crear paquetes de lanzamiento
   └─liquid # componentes CSS
```

## Uso

### Añadir CSS personalizado (recomendado)

Esta es la forma más sencilla de personalizar el tema.

Consulta <https://support.typora.io/Add-Custom-CSS/> para obtener ayuda.

### Modificar el archivo CSS publicado

Instala el tema Liquid en tu PC y luego modifica el archivo `xxxxx.css` en la carpeta del tema.

### Modificar el código fuente del proyecto

Descarga `Source code (zip)` desde la página de [Releases](https://github.com/ruiyangzhou01/Liquid/releases) del [repositorio Liquid](https://github.com/ruiyangzhou01/Liquid/), y luego modifica los archivos CSS en la carpeta `src`.
